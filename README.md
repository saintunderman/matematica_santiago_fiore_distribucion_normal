# Simulador de Distribución Normal (Gaussiana)

Una herramienta interactiva y educativa diseñada para visualizar y calcular probabilidades bajo la curva de una distribución normal. Ideal para estudiantes de estadística, ingeniería y ciencias que buscan comprender el comportamiento de la campana de Gauss de forma dinámica.

## Características Principales

* **Gráficos Interactivos:** Generación dinámica de la curva de Gauss basada en la media ($\mu$) y la desviación estándar ($\sigma$).
* **Cálculo de Probabilidades:** Permite calcular áreas bajo la curva en tres modalidades:
    * **Menor que ($$P(X < a)$$):** Probabilidad acumulada a la izquierda.
    * **Mayor que ($$P(X > a)$$):** Probabilidad a la derecha.
    * **Entre valores ($$P(a < X < b)$$):** Probabilidad en un intervalo específico.
* **Visualización en Tiempo Real:** Sombreado automático de la región calculada dentro del gráfico para una mejor interpretación visual.
* **Notación Matemática Profesional:** Integración con **MathJax** para mostrar las funciones de densidad de probabilidad y resultados en formato LaTeX.
* **Diseño Moderno:** Interfaz limpia, responsiva y optimizada para el aprendizaje.

## Cómo utilizarlo

1.  Abre el archivo en cualquier navegador moderno (Chrome, Firefox, Edge, etc.).
2.  https://saintunderman.github.io/matematica_santiago_fiore_distribucion_normal/
3.  Ingresa los parámetros de **Media** y **Desviación Estándar**.
4.  Selecciona el tipo de probabilidad que deseas calcular y observa cómo el gráfico se actualiza instantáneamente.

## Conceptos Estadísticos Incluidos

La aplicación sirve como recurso pedagógico para entender:
* La influencia de la media en el desplazamiento de la curva.
* Cómo la desviación estándar afecta el ancho (dispersión) de la campana.
* La relación entre la puntuación $Z$ y la probabilidad acumulada.
